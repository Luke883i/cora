# Backward semantic DoD — CORA holistic archaeology

**G scoped:** On a pinned Git revision, produce an explainable, source-replayable, non-destructive map of product/software/repository, historical change episodes and current file/development groups. No absence-as-proof, no automatic deletion, no AI authority.

**G+ NOT achieved:** cross-language/CFG/dataflow and external consumer closure, independently authenticated PR provenance, verified runtime coverage, calibrated AI confidence, protective GitHub rulesets, production-repository precision/recall and controlled transformation proof.

| Intermediate | Local falsifiable obligations |
| --- | --- |
| I1 provenance | L1 SHA-bound evidence; L2 Git diff/rename sources; L3 explicit history truncation |
| I2 ontology | L4 product/software/repo distinguished; L5 multi-role artifacts preserved |
| I3 clustering | L6 ≥2 independent cochange commits and Jaccard; L7 cross-product groups not auto-merged; L8 cap groups |
| I4 epistemics | L9 scaffold and gold are review hypotheses; L10 no safe-delete inference; L11 missing runtime/external/PR truth explicit |
| I5 AI & governance | L12 references checked; L13 missing evidence flagged; L14 confidence self-reported; L15 no executable authorization |
| I6 reproducibility | L16 corrupted and re-signed outputs rejected by Git replay; L17 dirty checkout does not change committed result |
| I7 usability | L18 one CLI / README; L19 independent real Git fixtures; L20 1M synthetic model cases twice + CI |

The million cases exercise a finite Boolean model; distinct input vectors are **not** a million independent repositories or a million distinct semantic output classes. Human and external-production validation are still open.

**Hardening addendum:** L7 also checks transitive ownership through undeclared bridges, and L3 ensures truncated history never qualifies an artifact as a short-lived scaffold. Independent negative Git fixtures must cover both counterexamples.
